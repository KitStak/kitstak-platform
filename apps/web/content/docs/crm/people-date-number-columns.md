These columns answer who, when and how much. People columns give items owners. Date and timeline columns drive the calendar, the timeline, My work and date automations. Number, currency and rating columns feed group sums, charts and the pipeline.

## People

1. Select the cell (**Assign people**).
2. Search with **Search names or roles**, or pick from **Suggested people**.
3. Select a person to add them. Select the remove button on a chip, or press `Backspace`, to take someone off.

| Setting | What it does |
| --- | --- |
| **Allow more than one person** | On by default. Turn off to allow one person per cell |

People you assign get a notification and see the item in **My work**. Someone who left the organization shows as **Former member**.

## Date

1. Select the cell (**Set a date**).
2. Pick **Today**, **Tomorrow**, **Next week** or **In 2 weeks**, or pick a day in the calendar.
3. Or type a date in **Type a date, e.g. next fri**. If the text can’t be read, you see **Can't read that date**.
4. If the column includes time, select **Add time** and enter a **Time**, for example `9:00 AM`.

| Setting | Options |
| --- | --- |
| **Date format** | **Short (Oct 30)**, **Long (Oct 30, 2026)**, **Relative (in 3 days)** or **ISO (2026-10-30)** |
| **Include time** | Adds a time to each date |

A date cell is colored by urgency: **Overdue** when the date is past, **Due today**, and **Due soon** within three days. When the item’s status is done, it shows **Done** instead.

## Timeline

A timeline holds a start and an end date.

1. Select the cell (**Set a timeline**).
2. Pick **This week**, **Next 2 weeks**, **This month** or **This quarter**, or pick a start and an end date.

Hover a filled cell to see the range and its length in days. Timelines draw the bars in the timeline view.

## Numbers

Type a number and press `Enter`. If the value isn’t a number, the change is not saved and a toast says so.

| Setting | Options |
| --- | --- |
| **Unit** | Up to 10 characters, for example `%` or `hrs` |
| **Unit position** | **Before the number ($10)** or **After the number (10%)** |
| **Decimals** | **None** to 4 |
| **Format** | `1,234,567`, **1.2M (compact)** or **Percent** |

## Currency

Type an amount and press `Enter`.

| Setting | Options |
| --- | --- |
| **Currency** | USD, EUR, GBP, CAD, AUD, JPY, CHF, INR, BRL or MXN |
| **Decimals** | **None**, 1 or 2 |

## Rating

Select a star to rate the item. Select the same star again to clear it. Empty cells show **Not rated**.

| Setting | Options |
| --- | --- |
| **Maximum rating** | 3 to 10 stars. The default is 5 |

## Change the group summary

Numbers, currency and formula columns show a summary in each group’s footer. Select the summary to switch between **Sum**, **Average**, **Median**, **Min**, **Max**, **Count** and **None**.
