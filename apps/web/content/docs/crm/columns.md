Columns describe your items: a deal’s stage, owner, value and close date are each a column. Every board starts with a **Name** column. You add the rest from 26 more column types.

## Before you start

- You need edit access to the board to add, change or delete columns.
- Anyone can sort, filter, resize or hide columns in their own view of the board.

## Add a column

1. Select **Add column** (the **+** at the right end of the column headers).
2. Pick a common type from the list, such as **Status**, **Text**, **People** or **Date**.
3. For anything else, select **More columns** to open the **Column Center**.
4. In the Column Center, search with **Search column types** or pick a category, then select the type.

The column is added at the right end. To add one next to an existing column, open that column’s menu and use **Add column to the right**.

## Column types

| Category | Types |
| --- | --- |
| **Text & labels** | **Text**, **Long text**, **Status**, **Dropdown**, **Tags**, **Checkbox**, **Files** |
| **People** | **People** |
| **Time management** | **Date**, **Timeline** |
| **Numbers & math** | **Numbers**, **Currency**, **Rating**, **Progress**, **Formula** |
| **Contact & location** | **Email**, **Phone**, **Link**, **Location**, **Country** |
| **Board power-ups** | **Connect boards**, **Mirror** |
| **Tracking & automation** | **Last updated**, **Creation log**, **Item ID**, **Button** |

The **Essentials** category in the Column Center shows the most used types: Status, Text, People, Date, Numbers and Dropdown. **Last updated**, **Creation log** and **Item ID** can be added only once per board.

## The column menu

Hover a column header and open its menu (**column actions**). The menu starts with the column type, for example **Status column**.

| Item | What it does |
| --- | --- |
| **Column settings** | Opens the settings dialog |
| **Edit labels** | Edits the labels of a status or dropdown column |
| **Filter by this column** | Opens a quick filter for this column |
| **Sort ascending**, **Sort descending**, **Clear sort** | Sorts the view by this column |
| **Autofit width**, **Autofit all columns** | Sizes columns to their content |
| **Collapse column** | Narrows the column to a thin strip. Select it to expand |
| **Rename** | Edits the title in the header |
| **Add description** or **Edit description** | Adds an info tooltip to the header |
| **Duplicate column** | **Structure only**, or **With values** |
| **Add column to the right** | Adds a column next to this one, or **More columns…** |
| **Change column type** | Converts the column to another type |
| **Hide column** | Hides the column in this view |
| **Delete column** | Removes the column, with **Undo** |

The **Name** column only offers the items that apply to it: it can’t be hidden, collapsed, retyped or deleted.

## Edit column settings

1. Open the column menu and select **Column settings**.
2. Edit the **Column name** and the **Description**. The description shows as an info tooltip in the header.
3. Change the type-specific settings, if the type has any.
4. Select **Save**.

A column name can be up to 255 characters and a description up to 2,000.

## Change a column’s type

1. Open the column menu and select **Change column type**.
2. Pick the new type.
3. Read the warning and select **Change type**.

Values that can be converted are kept. Values that don’t fit the new type are cleared, and this can’t be undone. You can’t convert to **Mirror**, **Button** or the once-per-board types.

## Arrange columns

- Drag a column by its header to reorder it.
- Drag the edge of a header to resize. Widths run from 40 to 1,200 pixels.
- Hide columns with **Hide column**, or with **Hide columns** in the toolbar. See [Search, filter, sort and group a board](/docs/crm/filter-sort-group).

Order, width and hidden columns are part of the view. Select **Save to this view** in the toolbar to keep them for everyone.

## Group summaries

The footer of each group summarizes its columns:

| Column type | Summary |
| --- | --- |
| Status, Dropdown, Checkbox | A colored bar showing how items split across labels, or how many are checked |
| Numbers, Currency, Formula | **Sum**, **Average**, **Median**, **Min**, **Max**, **Count** or **None**. Select the summary to change it |
| Rating, Progress | A number summary |
| Date, Timeline | The span from the earliest to the latest date |
| People | The people assigned in the group |
| Text and contact types | How many cells are filled |
