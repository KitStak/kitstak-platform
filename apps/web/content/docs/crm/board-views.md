A view is a way of looking at a board’s items. Every view reads the same items, so a change made in one view shows in all the others. Views appear as tabs under the board header, and each one keeps its own filters, sort, hidden columns and settings.

## View types

| View | What it shows |
| --- | --- |
| **Table** | The main grid: every column, group and summary |
| **Kanban** | Cards in lanes by stage or status. Drag to move them along |
| **Calendar** | Items on a month, week or day calendar by any date |
| **Timeline** | A Gantt-style plan of bars you can drag, resize and zoom |
| **Chart** | Bar, line, pie and stacked charts of any column, live |
| **Form** | A shareable form that creates an item for every response |
| **File gallery** | Every file on the board in one browsable gallery |

Dashboards open on their own page instead of a board tab. See [Create and share dashboards](/docs/crm/dashboards).

## Add a view

1. Select **Add view** (the **+** after the view tabs).
2. Under **Add a view**, pick a type.

The new view opens as a tab. You need edit access to the board to add views.

## The view tab menu

Open the menu on a view tab (**view options**).

| Item | What it does |
| --- | --- |
| **Rename view** | Edits the tab name |
| **Duplicate view** | Copies the view and its settings |
| **Set as default** | Makes this the view everyone lands on |
| **Copy link to view** | Copies a link that opens this view |
| **Delete view** | Removes the view. The items stay on the board |

The default view shows **This is the default view**. A board must keep at least one view. When there are too many tabs to show, the extra ones move into a menu such as **3 more**.

## Save changes to a view

When you filter, sort, hide columns or regroup, the toolbar shows **Unsaved changes**. These changes are yours until you save them.

- Select **Save to this view** to keep them for everyone who opens the view. You need edit access to the board.
- Select **Reset to the saved view** to drop your changes.

On kanban, calendar, timeline, chart and file gallery views, open **Customize** for the view’s own settings. Changes there apply instantly and are saved to the view.

## Table view tools

Open **More view options** (the **…** at the end of the toolbar) for **View tools** and **Row height**.

| Row height | Size |
| --- | --- |
| **Compact (32px)** | Fits more rows on screen |
| **Default (36px)** | The standard row |
| **Comfortable (40px)** | More space around each row |

## Move around the table with the keyboard

| Keys | Action |
| --- | --- |
| Arrow keys, `Tab`, `Home`, `End`, `Page Up`, `Page Down` | Move between cells |
| `Enter` or start typing | Edit the focused cell |
| `Delete` | Clear the focused cell |
| `Shift Space` | Select the row |
| `Ctrl A` or `Cmd A` | Select the group |
| `Ctrl Enter` or `Cmd Enter` | Open the item |
| `Ctrl C`, `Ctrl V` | Copy and paste cell values |
| `Esc` | Leave the grid |
