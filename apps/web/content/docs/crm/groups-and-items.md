Items are the rows of a board: one deal, one lead or one ticket each. Groups split a board into sections, such as stages, quarters or regions. Subitems break an item into smaller steps. The board’s terminology names them, so a Deals board says **New deal** where a generic board says **New item**.

## Before you start

- You need edit access to the board to add, change, move or remove items and groups.
- Viewers can open items and comment, but not change values.

## Add an item

Use any of these:

- Select **New item** (for example **New deal**) in the toolbar. The item is added at the top of the first group and opens in the item panel so you can name it.
- Type in the **+ Add item** row at the bottom of a group and press `Enter`.
- Open an item’s menu and select **Create new item above** or **Create new item below**.

Open the split menu next to **New item** for **New group of items** and **Import items**.

An item name is required. To rename an item, hover its name and select the pencil (**Rename**).

## Open an item

Hover the name and select **Open**, or select the row and press `Ctrl Enter` (`Cmd Enter` on a Mac). The item panel opens with its updates, files and activity. See [Open an item: updates, files and activity](/docs/crm/item-panel).

## The item menu

Hover a row and open its actions menu.

| Item | What it does |
| --- | --- |
| **Open item** (for example **Open deal**) | Opens the item panel |
| **Copy link** | Copies a link that opens the board with this item |
| **Create new item above** or **below** | Adds an empty item next to this one |
| **Add subitem** | Opens the subitems under this item |
| **Duplicate item** (for example **Duplicate deal**) | Copies the item and its values |
| **Move to** | Moves the item to another group, or **Another board…** |
| **Archive** | Takes the item off the board, with **Undo** |
| **Delete** | Moves the item to the trash, with **Undo** |

## Add subitems

1. Select the subitems toggle in the name cell (**Add subitems**), or use **Add subitem** in the item menu.
2. Type in the **+ Add subitem** row and press `Enter`.
3. Select **Hide subitems** to fold them away.

Subitems have their own columns. If there are none yet, the board offers **Add Owner, Status and Date**. Use the **+** at the end of the subitem header (**Add subitem column**) to add more. Subitems can’t have their own subitems.

## Work with groups

Add a group with **New group of items** in the toolbar split menu, or **Add group above** or **Add group below** in a group’s menu. The new group appears with a toast. Select its title to rename it.

Open a group’s menu (**group actions**) for:

| Item | What it does |
| --- | --- |
| **Collapse this group** or **Expand this group** | Folds or opens the group |
| **Collapse other groups**, **Collapse all groups**, **Expand all groups** | Folds or opens many at once |
| **Select all items** | Selects every item in the group |
| **Add group above**, **Add group below** | Adds a new group |
| **Duplicate this group** | Copies the group and its items |
| **Move to top** | Moves the group to the top of the board |
| **Move to board…** | Moves the group and its items to another board |
| **Rename group**, **Change group color** | Edits the group title or color |
| **Export group to CSV** | Downloads the group’s items |
| **Archive group** | Takes the group off the board |
| **Delete group** | Deletes the group and its items |

Shift-click a group’s collapse toggle to open or fold all groups. Drag a group by its handle to reorder groups.

A board must keep at least one group. When you delete a group with items, the dialog tells you how many items will be deleted too. You can undo right after, or restore from the trash for 30 days.

## Reorder and move items

- Drag a row by its handle to move it within a group or into another group.
- Use **Move to** in the item menu to pick a group, or **Another board…** to move it to another board.
- In **Move to board**, search with **Search boards** and pick a board. Matching columns keep their values.

## Edit many items at once

1. Select the checkbox on each row, or the group checkbox (**Select all items in this group**).
2. The selection bar opens at the bottom with the number selected.
3. Choose an action:

| Action | What it does |
| --- | --- |
| **Duplicate** | Copies every selected item |
| **Export** | Downloads the selected items |
| **Archive** | Archives them, with **Undo** |
| **Delete** | Moves them to the trash, with **Undo** |
| **Move to** | Moves them to a group, or **Another board…** |
| **Set value** | Sets one column to the same value on every selected item |

Press `Esc` or select **Clear selection** to close the bar. One bulk action can change up to 500 items.
