The item panel opens beside the board when you open an item. It is where the conversation about a deal or a ticket happens: updates and replies, the files attached to it, every field on one card and a log of every change.

## Open and move around the panel

1. On the board, hover an item’s name and select **Open**, or press `Ctrl Enter` (`Cmd Enter` on a Mac) on the row.
2. Use the previous and next arrows in the panel header (for example **Previous deal** and **Next deal**) to step through the items of the board.
3. Select **Expand to full page** in the item menu for more room, and **Collapse to side panel** to go back.
4. Select **Close panel** or press `Esc` to close it. Drag the panel edge (**Resize panel**) to change its width.

The header shows the board and group the item is in. Select the group name to jump to that group in the table. The link in your browser’s address bar opens the board with the item already open, so you can share it.

## Panel tabs

| Tab | What it holds |
| --- | --- |
| **Updates** | The conversation, with replies, reactions and pinned updates. The tab shows how many there are |
| **Files** | Every file on the item, from updates and file columns |
| **Activity log** | Every change to the item, who made it and when |
| Item card (for example **Deal card**) | Every field of the item, its subitems and the items that link to it |
| **Projects**, **Programs**, **Profit** | Work in other KitStak apps, when your plan includes them. See [Link CRM records to other KitStak apps](/docs/crm/connected-kitstak-apps) |

## Post an update

1. Open the **Updates** tab.
2. Select **Write an update and mention others with @**.
3. Write your update. Use the toolbar for **Bold**, **Italic**, **Strikethrough**, **Bulleted list**, **Numbered list**, **Checklist**, **Code**, **Add link** and **Emoji**.
4. Type `@` or select **Mention someone** to mention a teammate. They get a notification.
5. Select **Attach files** to add attachments.
6. Select **Post**, or press `Ctrl Enter` (`Cmd Enter` on a Mac).

Your draft is kept in this browser until you post it.

## Reply, react and pin

- Select **Reply** under an update, write in **Write a reply…** and select **Reply**.
- Select **Like**, or **Add reaction** to pick any emoji. Hover a reaction to see who reacted.
- **Seen by** shows who has read the update.
- Open the update menu for **Edit**, **Pin to top** (or **Unpin**), **Copy link** and **Delete**.

Only the author can edit an update. The author and organization admins can delete it, and a toast offers **Undo**. An edited update shows when it was edited.

## Files

The **Files** tab collects files from the item’s updates and its file columns.

1. Drag files onto the tab (**Drop to upload**) to add them.
2. Search with **Search files** and switch the layout between **Grid** and **List**.
3. Select a file to preview it. In the viewer, use **Previous file**, **Next file**, **Open** and **Download**.
4. Open a file’s menu to delete it. A toast offers **Undo**.

PDFs open in your browser’s viewer. Files without an inline preview show **No inline preview for this file type.**

## The item card

The card lists every column of the item, so you can fill in fields that are hidden in the table view. Hidden columns are marked **Hidden in the table view**.

- Add subitems with **Add subitem**.
- **Linked here** lists items on other boards that link to this one through a connect column.

## Activity log

The **Activity log** tab lists every change to the item. Use **Filter by column** and **Filter by person** to narrow it. Choose **Automations** in the person filter to see only changes made by automations.

## Subscribers

Subscribers get notifications about new updates on the item.

1. Select the subscriber avatars in the panel header.
2. Select **Subscribe me** or **Unsubscribe me**.
3. To add teammates, search in **Add teammates**.

## The item menu

| Item | What it does |
| --- | --- |
| **Copy link** | Copies a link to the item |
| **Open in new tab** | Opens the item in a new tab |
| **Print** | Prints the item |
| **Expand to full page** | Shows the panel full width |
| **Duplicate** (for example **Duplicate deal**) | Copies the item |
| **Move to group**, **Move to board** | Moves the item |
| **Archive**, **Delete** | Takes the item off the board |

On CRM boards, the header also shows **Convert** on leads, **Open 360 view** on contacts and accounts, and **Log activity** on contacts, accounts and deals. See [Convert a lead](/docs/crm/convert-a-lead) and [Account and contact 360 pages](/docs/crm/account-and-contact-pages).
