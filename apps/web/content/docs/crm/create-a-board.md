A board is a table of items, such as deals, leads or support tickets, arranged in groups and described by columns. You can create one from scratch, start from a template, or install the whole CRM suite at once.

## Before you start

- You need the member role or higher, unless an admin changed **Who can create boards**. See [Roles, teams and permissions](/docs/crm/roles-and-permissions).
- You need at least one workspace. See [Create workspaces and folders](/docs/crm/workspaces-and-folders).

## Create a board

1. Open **Workspaces** in the top bar, select the add button (**Add to workspace**) and choose **New board**. You can also use **New board** on Home or the command **Create board** in search.
2. Enter a **Board name**, for example `Q3 enterprise pipeline`.
3. Under **What are you managing in this board?**, pick an **Item type**: **Deals**, **Leads**, **Contacts**, **Accounts**, **Activities**, **Projects**, **Tasks**, **Items** or **Custom…**.
4. If you picked **Custom…**, enter a **Custom name for one row**, for example `Shipment`.
5. Choose the **Privacy**. See the table below.
6. Pick the **Workspace** and, optionally, a **Folder**.
7. Turn **Include sample data** on or off.
8. Select **Create board**.

The preview on the right shows how the board will look. The CRM item types (Deals, Leads, Contacts, Accounts and Activities) use the matching CRM template, with its columns, groups and views. **Tasks**, **Items** and custom types start blank with a Name column, a Status and a Date.

| Privacy | Who can see the board |
| --- | --- |
| **Main** | Everyone in the workspace can find and open it |
| **Private** | Only people you invite can see it |
| **Shareable** | Members can invite guests from outside your organization |

The item type sets the board’s terminology. Buttons, counts and empty states then say **New deal** or **New lead** instead of **New item**. You can change it later in **Board settings**.

## Start from a template

1. Open the add menu and select **Choose from templates**, or select **Browse templates** in the create dialog.
2. In the **Template center**, search with **Search templates, columns or use cases**, or pick a category: **Recommended**, **All templates**, **CRM**, **Sales**, **Marketing**, **Customer success**, **Projects**, **Operations**, **HR** or **Start from scratch**.
3. Select a template to preview it. The detail shows **What’s included**, its **Columns** and what it is **Good for**.
4. Select **Use template**, then name the board and choose where it goes.
5. Select **Create from “Leads”** (the button names the template you picked).

Templates in the library include Leads, Deals, Accounts, Contacts, Activities, Customer onboarding, Renewals, Quotes & proposals, Partner pipeline, Campaign planner, Events & webinars, Support tickets, Project tracker, Vendor management, Request intake, Recruiting pipeline and Employee onboarding. Templates marked **Includes form** come with a form view.

## Install the CRM suite

The CRM suite builds a new workspace with Leads, Deals, Accounts, Contacts and Activities, connects them to each other and adds a sales dashboard.

1. Open the **Template center** and select the CRM suite.
2. Select **Install CRM suite**.
3. Enter a **Workspace name**.
4. Leave **Include sample data** on to get example deals, leads and accounts. You can delete them any time.
5. Start the install and wait for the progress steps to finish.

A toast confirms the workspace is ready, with the number of connected boards created and a dashboard.

## Save a board as a template

Open a board’s menu (**More board actions**) and select **Save as template**. You need edit access to the board. KitStak makes a copy of the board’s structure named after it, for example `Q3 enterprise pipeline template`, and a toast confirms **Saved as a template**. The copy keeps the columns, groups and views, without items.

## Rules

- A board name is required and can be up to 255 characters.
- The board always has a **Name** column and at least one group and one view.
- If a template is no longer available, the template center says so and shows similar templates.
