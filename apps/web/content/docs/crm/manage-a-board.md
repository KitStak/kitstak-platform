The board header sits above every view of a board. It shows where the board lives, its name and description, its members, and the buttons for automations, integrations, the activity log and sharing. The board menu holds everything else you can do with the board as a whole.

## Before you start

- Anyone who can open a board can favorite, copy its link, export, print and read its activity log.
- Renaming, moving, archiving, deleting and changing settings need edit access to the board.

## The board header

| Part | What it does |
| --- | --- |
| Breadcrumb | Shows the workspace and folder. Select a part to go there |
| Board info | Shows **Description**, **Owners**, **Created**, **Workspace** and **Privacy** |
| Board name | Select it to rename the board in place |
| Star | **Add to favorites** or **Remove from favorites** |
| Description line | Select it to edit. Empty boards show **Add board description** |
| Member avatars | Opens the share dialog to manage members |
| **Integrate** | Opens the **Integrations** tab of the board’s automations |
| **Automate** | Opens the board’s automations. The badge shows how many it has |
| **Activity log** | Opens the board activity drawer |
| **Invite** | Opens the share dialog |
| **More board actions** | Opens the board menu |

## Change board settings

1. Open **More board actions** and select **Board settings**.
2. Edit **Item terminology**, the name for one row, such as `Deal` or `Opportunity`. Buttons, counts and empty states then say **New deal**.
3. Edit the **Description**.
4. Pick the **Default view**, the view everyone lands on when they open the board.
5. Save. A toast confirms **Board settings saved**.

Item terminology can be up to 40 characters.

## The board menu

| Group | Items |
| --- | --- |
| **View** | **Collapse header** or **Expand header**, **Open in new tab**, **Copy board link** |
| **Board** | **Add to favorites**, **Rename board**, **Duplicate board…**, **Move to…**, **Save as template**, **Permissions & privacy** |
| **Data** | **Export this view** (**Excel (.xlsx)** or **CSV (.csv)**), **Import data…**, **Print**, **Board settings** |
| **Activity & integrations** | **Activity log**, **Automations**, **Integrations** |
| Last | **Archive board**, **Delete board…** |

## Duplicate a board

1. Select **Duplicate board…**.
2. Choose what to copy:

| Option | What is copied |
| --- | --- |
| **Structure only** | Columns, groups and views. No items |
| **Structure and items** | Everything on the board, without updates |
| **Structure, items and updates** | A full copy including the conversation |

3. Enter a **New board name** and confirm. The copy goes in the same workspace.

You can also duplicate from the board’s menu in the Workspaces tree.

## Move a board

1. Select **Move to…**.
2. Choose a **Workspace** and a **Folder**, or **No folder (workspace root)**.
3. Confirm the move.

## Archive or delete a board

- **Archive board** keeps the board but makes it read-only. A banner says **This board is archived. It’s read-only until you restore it.** People with edit access can select **Restore board**.
- **Delete board…** asks you to confirm **Delete board**. The board and all its items move to the trash. You can undo right after, or restore it from the trash for 30 days.

If someone else deletes a board while you have it open, you see that it is in the trash and that a board owner can restore it.

## Read the activity log

1. Select **Activity log** in the header.
2. Use **Filter by person, item or column** to narrow the list.

The log shows changes to items, columns and groups, who made them and when. Changes made by automations show **Automation** as the author.
