Widgets are the building blocks of a dashboard. Each one reads items from the boards connected to the dashboard, or from boards it picks itself, and shows them as a number, a chart, a list or a plan.

## Before you start

- You need to be able to edit the dashboard. See [Create and share dashboards](/docs/crm/dashboards).
- Connect the boards the widgets will read from.

## Add a widget

1. Open the dashboard and select **Add widget**.
2. Under **Add a widget**, search with **Search widgets** or pick a category: **All widgets**, **Popular**, **Charts & reports**, **Sales & pipeline**, **Time & people** or **Content**.
3. Pick a widget. Shape it with live data in the preview.
4. Pick a size: **Small**, **Medium** or **Large**.
5. Add it. It drops into the first free spot, and you can drag it anywhere afterwards.

For a faster start, use **Quick add** in the toolbar, or **More widgets…** for the full gallery.

## Widgets

| Widget | What it shows |
| --- | --- |
| **Numbers** | One headline KPI with trend vs the previous period, sparkline and goal |
| **Chart** | Bar, stacked, line, area, pie or donut over any column |
| **Battery** | Progress at a glance: how items split across status labels |
| **Table** | A filtered, sortable list of items across boards |
| **Funnel** | Stage-by-stage conversion for a pipeline status column |
| **Forecast** | Pipeline, probability-weighted and won value by close month |
| **Leaderboard** | Rank people by deals won, revenue or any number |
| **Workload** | Who has too much on their plate, week by week against capacity |
| **Calendar** | Items on a month calendar by any date column |
| **Timeline** | A Gantt-style summary of item timelines with a today line |
| **Countdown** | Days, hours and minutes to a quarter close or launch |
| **Text** | A note, link list or instructions for the team |
| **Section header** | A full-width heading that groups the widgets below it |

## Widget settings

Open the widget menu (**Widget actions**) and select **Settings**, or select **Widget settings** on the widget. The sections depend on the widget.

| Section | Settings |
| --- | --- |
| **General** | Title and **Subtitle** |
| **Data source** | The boards to read from: the ones **Connected to this dashboard**, or others in the workspace |
| **Number** | **Calculation** (**Count items**, **Sum**, **Average**, **Median**, **Minimum**, **Maximum**) and **Column**, **Format** (**Number**, **Currency** or **Percent**), **Prefix**, **Suffix**, **Goal**, **Icon**, **Trend date column**, **Compare with previous period**, **Show sparkline** |
| **Chart** | **Chart type**, **X-axis (group by)** (**Board group**, **Board**, **Date** or a column), **Date column** and **Bucket** (**Week**, **Month**, **Quarter**), **Stack by**, **Sort**, **Show top**, **Show legend**, **Show values on bars** |
| **Battery** | **Status column**. Labels marked as done count toward the percentage |
| **Leaderboard** | **Rank people from** a column, and how many to show |
| **Workload** | **People column**, **Date or timeline column**, **Capacity per person per week** |
| Calendar and timeline | The date or timeline column and **Color by** |
| **Table** | **Columns**, **Sort by** and **Rows** |
| **Funnel**, **Forecast** | **Stage column**, **Value column**, **Probability column (%)**, **Close date column**, **Months**, **Leave out stages** |
| **Text** | **Content**, with bold, italic, lists, headings and links |
| **Countdown** | **Target date** and **Time** |
| **Filter** | **Only items where** a column meets a **Condition** |
| **Colors** | **Accent color** and a color per value |

Numbers accept short forms such as `30M` or `1.5k`.

## The widget menu

| Item | What it does |
| --- | --- |
| **Settings** | Opens the widget settings |
| **Rename** | Edits the title |
| **Duplicate** | Copies the widget |
| **Full screen** | Shows the widget large |
| **Refresh data** | Reloads the widget |
| **Export CSV** | Downloads the widget’s data |
| **Delete widget** | Removes it |
