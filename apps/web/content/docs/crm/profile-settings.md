Your profile tells teammates who you are when you are assigned, mentioned or listed as an owner. Your preferences change how the CRM looks and shows dates for you only.

## Open your profile

1. Select your avatar in the top bar.
2. Select **My profile** (or **Preferences**).

The page is **My profile**. Its tabs are **Personal info**, **Preferences**, **Notifications**, **Password & sessions** and, when your role can create tokens, **API tokens**.

## Personal info

Select a field, type the new value and press `Enter` to save (`Esc` cancels).

| Field | Notes |
| --- | --- |
| **Profile photo** | Select the picture at the top of the page to upload or replace it |
| **Full name** | Can’t be empty |
| **Title** | For example `Account Executive` |
| **Email** | Used to sign in. You can’t change it here |
| **Phone** | Digits, spaces and `+ ( ) -` only |
| **Location** | For example `Austin, USA` |
| **Time zone** | Search cities or regions |
| **Role** | Set by an admin |

## Preferences

| Setting | Options |
| --- | --- |
| **Theme** | **Light**, **Dark** or **System**. System follows your operating system |
| **Language** | Your language and region, such as **English (United States)** or **Deutsch (Deutschland)** |
| **Date format** | `MM/DD/YYYY`, `DD/MM/YYYY` or `YYYY-MM-DD` |
| **Time format** | The preview shows the current time in the format you pick |
| **Week starts on** | **Sunday** or **Monday** |

A toast confirms **Preferences saved**. You can also switch the theme from the account menu under **Theme**.

## Notifications

The **Notifications** tab lists each event, such as **Someone @mentions me** or **I’m assigned to an item**, with a choice per channel. Changes save automatically. See [Notifications and the bell](/docs/crm/notifications) for what reaches your bell.

## Change your password

1. Open the **Password & sessions** tab.
2. Under **Change password**, enter your **Current password**.
3. Enter a **New password** of 10 to 72 characters and repeat it in **Confirm new password**.
4. Leave **Sign out of all other devices** on if you think someone else knows your password.
5. Select **Update password**. A toast confirms **Password changed**.

The new password must be one you haven’t used here. If the current password is wrong, you see **That password isn’t correct**.

## Sign out other sessions

**Where you’re signed in** lists each session with its device and IP address. **This device** marks the one you are using.

- To end one session, select **Sign out** on its row.
- To end every other session, select **Sign out all other sessions** and confirm **Sign out others**. You stay signed in here.

## API tokens

The **API tokens** tab is where you create personal tokens for scripts and integrations. See [Personal API tokens](/docs/crm/api-tokens).
