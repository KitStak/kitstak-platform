Every page in KitStak CRM shares one top bar. It holds the main navigation, search, notifications, help and your account menu. This page explains each part and the keyboard shortcuts that get you anywhere without the mouse.

## The top bar

From left to right:

| Part | What it does |
| --- | --- |
| KitStak logo | Goes to **Home** |
| **Home** | Your start page. See [Use the Home page](/docs/crm/home-page) |
| **My work** | Everything assigned to you. See [Track your assignments in My work](/docs/crm/my-work) |
| **Inbox** | Updates on items you follow. See [Read and reply in the Inbox](/docs/crm/inbox) |
| **CRM** | Menu with **Pipeline**, the CRM boards and **Duplicates** |
| **Workspaces** | The workspace switcher and the tree of folders and boards |
| Star menu | Your **Favorites** |
| Search | Opens search and commands |
| Bell | Your notifications. See [Notifications and the bell](/docs/crm/notifications) |
| **Invite members** | Invite people to the organization (shown when your role can invite) |
| **Help** | Setup guide, shortcuts, help center, support and feedback |
| App switcher | Moves between the KitStak apps in your plan |
| Your avatar | Your account menu |

On a phone, select **Open navigation** to open the same destinations in a drawer.

## The CRM menu

**CRM** lists the CRM pages that exist in your organization:

- **Pipeline**, when you have a Deals board. See [Read the pipeline and forecast](/docs/crm/pipeline).
- **Deals**, **Leads**, **Contacts**, **Accounts** and **Activities**, each opening its board.
- **Duplicates**, when you have a Contacts or Accounts board. See [Find and merge duplicate records](/docs/crm/duplicates).

If no CRM boards exist yet, the menu is hidden. Install the CRM suite from the template center to add them. See [Create a board from scratch or a template](/docs/crm/create-a-board).

## The Workspaces menu

Select **Workspaces** to open the switcher and the tree.

1. Pick a workspace from the switcher at the top.
2. Expand folders and select a board or dashboard to open it.
3. Select the search icon (**Search in workspace**) to filter the tree with **Filter boards and folders**.
4. Use the add button (**Add to workspace**) to create a board, dashboard or folder, choose from templates or import data.

See [Create workspaces and folders](/docs/crm/workspaces-and-folders) for the workspace and folder menus.

## Favorites

Star a board, dashboard, folder or workspace to pin it. Open the star menu in the top bar to see them. If you have none, it says **Star boards, dashboards and folders to pin them here.**

To remove a favorite, hover it in the list and select **Remove from favorites**.

## Search and commands

1. Select the search box in the top bar, or press `Ctrl K` (`Cmd K` on a Mac).
2. Type to search items, boards and people: **Search items, boards, people… or type a command**.
3. With an empty search, the **Go to** group lists Home, My work, Inbox, Pipeline and Dashboards.
4. Type a command name to run it: **Create board**, **Import data**, **Invite members**, **Open the Workspaces menu** or **Keyboard shortcuts**.
5. Use the arrow keys to move and `Enter` to open. Press `Esc` to close.

## Keyboard shortcuts

Press `?` anywhere (outside a text field) to open **Keyboard shortcuts**.

| Keys | Action |
| --- | --- |
| `Ctrl K` or `Cmd K` | **Search & commands** |
| `Ctrl \` or `Cmd \` | **Open the Workspaces menu** |
| `G` then `H` | **Go to Home** |
| `G` then `M` | **Go to My work** |
| `G` then `I` | **Go to Inbox** |
| `G` then `D` | **Go to Dashboards** |
| `G` then `P` | **Go to Pipeline** |
| `?` | **Show keyboard shortcuts** |
| `Esc` | **Close menu, panel or dialog** |

Press the second key of a `G` shortcut within about a second of the first. Shortcuts do nothing while you type in a field or while a menu or dialog is open.

## The Help menu

| Item | What it does |
| --- | --- |
| **Setup guide** | Reopens the getting-started checklist on Home |
| **Keyboard shortcuts** | Opens the shortcuts list |
| **Help center** | Opens these docs in a new tab |
| **Contact support** | Starts an email to KitStak support |
| **Give feedback** | Starts an email to send feedback |

## The account menu

Select your avatar to open it. It shows your organization and your role, and holds **My profile**, **Theme** (**Light**, **Dark** or **System**), **Keyboard shortcuts**, **Preferences**, **Trash** and **Log out**. Admins also see **Administration** and **Plan and payment**. People who can manage members see **Members & teams**.
