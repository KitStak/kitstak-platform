The Inbox is a feed of the conversations that concern you. Updates on items you own, follow or are mentioned in land here, newest first. You can read, like and reply to them without opening each board.

## Open the Inbox

Select **Inbox** in the top bar, or press `G` then `I`. Home also shows your unread count with an **Open** link.

## Filter the Inbox

| Tab | What it shows |
| --- | --- |
| **All updates** | Every update that concerns you |
| **Mentions** | Updates where someone @mentioned you |
| **Unread** | Updates you haven’t read yet |

Use the board filter (**All boards** or one board) to narrow the feed. Scroll down to load older updates.

## Read and reply

Each card shows the author, where the item lives (its board and group), the update and its replies.

1. Select **Show more** to read a long update, and **Show less** to fold it.
2. Select **Like** to like it. Select it again (**Unlike**) to take the like back.
3. Select **Reply**, write in **Reply to**, mention others with `@`, and send.
4. Select the item’s location to open the item on its board.

Replying marks the update as read.

## Mark as read or unread

Unread updates and replies are marked on the card. Select **Mark as read** or **Mark as unread** on a card to change it.

## Empty states

| Message | Meaning |
| --- | --- |
| **Inbox zero** | Nothing concerns you yet |
| **No mentions** | No one has @mentioned you |
| **You're all caught up** | You have read everything |
| **No updates on this board** | Try another board or clear the filter |
