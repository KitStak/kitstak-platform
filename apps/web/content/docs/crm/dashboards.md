A dashboard puts widgets from one or more boards on one page: KPIs, charts, a forecast, a leaderboard and more. Widgets update live as the boards change, so the numbers in your weekly review are always current.

## Before you start

- Members, admins and owners can create and edit dashboards. Viewers can open the dashboards they have access to.
- A dashboard reads from boards you connect to it, up to 20. Create the boards first, or start with text widgets.

## Open the dashboards list

Press `G` then `D`, or use **Dashboards** in search. The list has **Search dashboards** and a **Show** filter: **All** or **Favorites**. Private dashboards show a lock.

On each card, open **Actions for** the dashboard to open, favorite, duplicate or delete it.

## Create a dashboard

1. On the dashboards list, select **New dashboard**.
2. Under **Details**, enter a **Name**, for example `Q4 sales cockpit`, and an optional **Description**.
3. Pick the **Workspace**.
4. Under **Privacy**, pick **Workspace** (everyone in the workspace can view) or **Private** (only you and admins).
5. Select **Next** to go to **Boards & layout**.
6. Under **Connect boards**, pick the boards widgets should read from.
7. Under **Start with**, pick **Sales cockpit** (KPIs, forecast, funnel, leaderboard and top deals), **Starter widgets** (a KPI, a progress battery, a chart and a list) or **Blank canvas**.
8. Select **Create dashboard**.

You can also create one from the Workspaces menu with **New dashboard**. The CRM suite adds a sales dashboard for you.

## Arrange widgets

- Select **Add widget** in the toolbar to open the widget gallery, or **Quick add** for common widgets. See [Add and configure dashboard widgets](/docs/crm/dashboard-widgets).
- Drag a widget by its header to move it. Drag its corner to resize it.
- Open **Dashboard options** and select **Tidy up layout** to close gaps. A toast offers **Undo**.
- Turn on **Lock layout** to stop widgets from moving. The toolbar shows **Locked**. Select it to unlock.

## Filter a dashboard

The toolbar filters apply to every widget.

| Filter | What it does |
| --- | --- |
| **Search items** | Narrows every widget to matching items |
| Connected boards | Adds or removes boards. **Include new boards in existing widgets** also adds them to widgets you already have |
| **Filter by person** | Shows one person’s items |
| **Date range** | **All time**, **This month**, **Last month**, **This quarter**, **Last quarter**, **Next quarter**, **Last 30 days**, **Last 90 days**, **Next 90 days**, **Year to date** or **Custom range** |

Select **Clear filters** to remove them all. Filters are yours. To share them, copy a link that keeps them.

## Keep it fresh

- The toolbar shows when the data was last updated, for example **Updated just now**.
- Select **Refresh all widgets** to reload now. If a widget could not refresh, it shows older data with **Couldn’t refresh** and a **Retry**.
- In **Dashboard options**, set **Auto refresh** to **Off**, **Every minute**, **Every 5 minutes** or **Every 15 minutes**.

## Share a dashboard

1. Select **Share**.
2. Copy the link with **Copy link**. Turn on **Include the current filters in the link** to send your view.
3. Under **Who can see it**, pick **Everyone in the workspace** (members can view, editors can change widgets) or **Private** (only you and organization admins).

**People with access** lists the owner and who can view. Anyone with access sees live data from the connected boards.

## Present on a screen

Select **Present (TV mode)** in the toolbar or in **Dashboard options**. In presentation mode you can rotate through dashboards: **No rotation**, **Rotate every 30 s**, **Rotate every minute** or **Rotate every 2 min**. Press `Esc` to leave.

## The dashboard options menu

| Item | What it does |
| --- | --- |
| **Present (TV mode)** | Full-screen presentation |
| **Copy link with filters** | Copies a link that keeps your filters |
| **Export as PDF** | Saves the dashboard as a PDF |
| **Duplicate dashboard** | Makes a copy |
| **Tidy up layout**, **Lock layout** | Arranges or locks widgets |
| **Auto refresh** | Sets how often widgets reload |
| **Privacy** | **Workspace: everyone in the workspace** or **Private: only me and admins** |
| **Delete dashboard** | Moves the dashboard and its widgets to the trash. Boards are not affected |
