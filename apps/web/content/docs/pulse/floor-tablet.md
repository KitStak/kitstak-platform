The floor tablet is a shared tablet on the floor for logging units, people and hours. It needs no sign in. People tap their name, type a 4 digit PIN and log one job at a time. The tablet never shows money, and entries are saved under the person who unlocked it.

## Before you start

- Making device links needs a manager, admin or owner.
- Each person who logs on the tablet needs a PIN. An admin sets PINs for others. Anyone can set their own.
- Jobs show on the tablet once they are active and their start day has come.

## Make a floor tablet link

1. Go to **More > Settings** and open **Device links**.
2. Under **Floor tablets**, type the **Name of the device**, like "Line 2 tablet", and pick the **Site for the device**.
3. Select **Make a link**.
4. Select **Copy link**, open it on the tablet and leave that page open.

A link serves one site. Each link shows when it was last opened and **Works until** a date. A link works for 90 days. When it runs out it reads **Ran out**. Select **Turn on for 90 days** to make the same link work again. To stop a tablet, select **Turn off**: the tablet shows that the link is not active.

## Set PINs

- For someone else: go to **Settings > People and roles**, select **Set PIN** (or **Reset PIN**) for the person, type 4 digits and save. Tell them the 4 digits in person. Leave it empty to remove the PIN.
- For yourself: in **Device links**, under **Tablet PINs**, set **Your new PIN**.

Only people with a PIN show on the tablet. With nobody set up, the tablet says **Nobody has a PIN yet**.

## Log on the tablet

1. On **Who is logging?**, tap your name.
2. Type your 4 digit PIN.
3. On **Which job?**, tap the job card. Each card shows what was logged today.
4. Type the units finished on the number pad.
5. Set **People** and **Hours each** with the plus and minus buttons. The tablet shows the labor hours and the pace against the target as you go.
6. Select **Save**. A big confirmation shows today so far on the job.
7. Select **Next job**, or **Lock** when you are done.

## Safety rules

| Rule | What happens |
| --- | --- |
| Wrong PIN | After 5 wrong tries, that name is locked for 5 minutes. |
| Idle | The tablet locks itself after 2 minutes with no touch. |
| Money | The tablet never shows money. |
| One site | The tablet lists the jobs of its link's site only. |

## When the wifi drops

You can keep logging. Each entry waits on the tablet with **Saved on this tablet. Will send when online.** When the tablet is back online it sends them, oldest first, with the same id each time, so nothing is logged twice. Checking a PIN needs wifi.
