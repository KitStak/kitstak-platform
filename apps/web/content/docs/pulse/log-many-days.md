The **Many days** tab of Log work is a small spreadsheet for catching up. One row is one job on one day. Fill a run of days for a job, or paste rows from your own sheet, then save everything in one go. Nothing is saved until you press **Save all rows**.

## Before you start

- You need a role that can log work: supervisor, manager, admin or owner. Supervisors can log the last 7 days.
- For many days from a time clock or another system, an import may be faster. See [Import a CSV file](/docs/pulse/import-csv).

## Fill a run of days for one job

1. Go to **Log work** and open the **Many days** tab.
2. In **Job to fill**, pick the job.
3. Pick the **First day** and the **Last day**.
4. Select **Add the days**.

Pulse adds one row for each work day in the range, with the usual crew filled in. Days that are already logged come in with their numbers.

## Paste rows

1. In your spreadsheet, copy rows in this column order: day, job number, units good, scrap, people, hours each, labor hours, note.
2. Click into the sheet and paste.

Pulse says how many rows it pasted and which ones it left out, and why. A header row is left out on its own.

## The columns

| Column | What to type |
| --- | --- |
| **Day** | The work day. A day in the future is refused. |
| **Job** | The job number or name. |
| **Units good** | Good units finished. |
| **Scrap** | Units thrown away. |
| **People** | How many people. |
| **Hours each** | Hours each person worked. |
| **Labor hours** | People times hours each. You can type over it. |
| **Note** | Anything worth knowing. |
| **Check** | The pace against the target, or the problem with the row. |

Each row can be duplicated for the next work day or removed from the sheet.

## Save the sheet

Select **Save all rows**. The save is all or nothing: if one row has a problem, nothing is saved and Pulse names the row and the problem. Fix it and save again. A good save says how many rows were new and how many changed, and can be undone.

Common problems:

- **Pick a job for this row.**
- **Type units, or people and hours. Or remove the row.**
- **This job already has a row for this day above. Add the numbers together.**
- **This day is in the future.**
