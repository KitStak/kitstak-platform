These pages are about you, not the company. The notification center collects alerts about waves, imports, exports, shortages and integrations. Your profile, password and preferences change how you sign in and how dates and numbers look on every screen.

## Before you start

- Every user can open their own notifications, profile, password and preferences pages.

## Notifications

The bell in the header shows how many notifications you haven't read. Open it for the latest ones, **Mark all read**, or **View all notifications**.

The **Notifications** page lists them all.

| Control | What it does |
| --- | --- |
| **All**, **Unread** | Show everything or only unread ones, with the unread count. |
| **All types** and type chips | Filter by kind, such as waves, imports, exports, jobs, orders, receiving, counts or integrations. |
| Severity | **Any severity**, **Needs attention**, **Success** or **Info**. |
| Date | **Any time**, **Today**, **Last 7 days** or **Last 30 days**. |
| **Mark all read** | Marks every notification as read. |
| **Clear read** | Deletes every read notification. Unread ones are kept. This can't be undone. |

Select a notification to open the screen it is about; it is marked read. Each one also has buttons to mark it read or delete it. A notification that reports shortages, skipped items or failures always shows as needing attention, even when the work itself finished.

## My Profile

Open the user menu in the header and select **My Profile**.

| Field | What it does | Required |
| --- | --- | --- |
| **Display name** | Shown in the header, on tasks and in change logs. Up to 80 characters. | Yes |
| **First name**, **Last name** | Up to 60 characters each. | Yes |
| **Email** | Used to sign in. | Yes |
| **Current password** | Shown when you change the email: confirm it's you. | When the email changes |

Select **Update my profile**. The page also shows your roles, user type, client access and when your password last changed.

## Change Password

Select **Change Password** in the user menu.

1. Enter the **Current password**.
2. Enter the **New password** and **Re-enter new password**. It must meet your company's password policy.
3. Select **Change password**.

Every other device is signed out. The browser you are using stays signed in. After an administrator resets your password, KitStak opens this page first with **Choose a new password to keep working**.

## Preferences

Select **Preferences** in the user menu.

| Field | Options |
| --- | --- |
| **Date format** | Pick a format from the list. New users start on the company default. |
| **Time format** | **12 hour**, such as 4:05 PM, or **24 hour**, such as 16:05. |
| **Number format** | **Thousand separator** (1,025.00) or **Decimal separator** (1.025,00). |

A preview shows a sample date and number in your formats. Select **Save and apply changes**: every grid and summary uses the new formats. The time zone is shown too; it is set by your warehouse, and only an administrator can change it.
