Every screen in KitStak WMS shares the same top bar, the same search and the same grid. Learn them once and every page works the same way.

## The top bar

From left to right, the top bar shows:

- Your company logo, or the KitStak logo. Select it to go to the **Dashboard**.
- The menus: **Fulfillment**, **Inventory**, **Automation**, **Integrations**, **Reports**, **Analytics** and **Settings**. Menus and pages you have no permission for are hidden.
- Global search.
- The working context switcher (warehouse and client).
- **Transactions**, **Printers**, **Help center** and **Notifications**.
- The app switcher, to move to other KitStak apps.
- Your account menu.

On a phone or a handheld, the menus fold into one menu button at the left. **Transactions** and **Printers** are hidden on small screens so the page never scrolls sideways.

## Search pages and records

1. Press `/` or `Ctrl+K`, or select the search box.
2. Type a page name or a code. The search box reads **Search pages, orders, POs, SKUs, LPs, locations, users…**
3. Pick a result. Results are grouped as **Pages**, **Orders**, **Purchase Orders**, **Products**, **License Plates**, **Locations**, **Jobs**, **Clients**, **Users** and **Roles**.

Recent searches show when the box is empty. You can type a code with fewer zeros, such as `PO22`.

## Set the working context

The context switcher narrows lists and dashboards to one warehouse and one client.

1. Select the context chip in the top bar.
2. Under **Working context**, choose a **Warehouse** or **All warehouses**, and a **Client** or **All clients**.
3. Select **Apply**.

Your choice is remembered on this device.

## Header tools

| Tool | What it does |
| --- | --- |
| **Transactions** | Shows exports, imports and bulk operations running in the background, with status **Queued**, **Started**, **Completed** or **Error**. Download finished files here. |
| **Printers** | Assigns a barcode printer and a laser printer per warehouse. Select **Test label** to check the barcode printer, then **Save**. Needs the Direct Print agent on your computer. |
| **Help center** | Opens the help panel with guides and articles for the page you are on. |
| **Notifications** | Shows recent notifications with an unread count. Select **Mark all read**, or **View all notifications** for the full list. |

## Your account menu

Select your avatar to open the account menu. It lists **My Profile**, **Change Password** and **Preferences**, plus **Company Settings** and **Apps** when your role allows them. **Appearance** switches between **Light**, **Dark** and **Match system**. **Sign out** ends this session. **Sign out all sessions** ends every session on every device.

In **Preferences** you choose the date, time and number formats used in every grid.

## Keyboard shortcuts

Press `?` to see every shortcut. The most used ones:

| Keys | Goes to |
| --- | --- |
| `G` then `D` | Dashboard |
| `G` then `R` | Receiving (purchase orders) |
| `G` then `I` | Inventory |
| `G` then `P` | Products |
| `G` then `L` | Locations |
| `G` then `O` | Shipment orders |
| `G` then `J` | Jobs |
| `G` then `C` | Clients |
| `G` then `T` | Reports |
| `G` then `S` | Settings |
| `Esc` | Closes a dialog, menu or drawer |

Shortcuts are ignored while you type in a field.

## Work with grids

Most pages are a grid with the same toolbar:

- **Search.** Type in the search box and press `Enter`.
- **Filter.** Add filters by field. Applied filters show as chips above the grid.
- **Columns.** Show, hide and reorder columns.
- **Saved views.** Select **Save view** to keep the filters and columns. Turn on **Share with my team** or **Set as my default view** if you want.
- **Export As Excel.** Exports the grid. The file appears in **Transactions**.
- **Row actions.** Each row has an actions menu, such as **Show details**, **Edit** or **Change log**.
- **Bulk actions.** Select rows with the checkboxes, then use the buttons above the grid. A disabled button shows why when you point at it.

Shift and click a column header to add it to the sort.

## Idle sign out

If your company turns on idle sign out, a dialog named **Are you still there?** counts down before you are signed out. Select **Stay signed in** to keep working, or **Sign out now**.
