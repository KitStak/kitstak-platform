The **Dashboard** is the first page after you sign in. It shows today's work for the warehouses and clients you choose, and refreshes on its own every 60 seconds. New installs also see the **Get set up** checklist at the top.

## Open the dashboard

- Select **Dashboard** in the top bar, or the logo.
- Or press `G` then `D`.

## What the dashboard shows

| Card | What it shows |
| --- | --- |
| **Progress for Today** | **Tasks** completed, **Order Lines** and **Orders Due Today**, with the day shift clock of the warehouse. |
| **Unfulfilled Orders** | Open orders by order age, split into **Open** and **In Progress**, with **Total Orders** and **Total Pack Qty**. |
| **Order Breakdown by Status** | How many orders sit in each status. |
| **Channels** | Orders ranked by sales channel. |
| **Clients** | Orders ranked by client. |
| **Carriers** | Orders ranked by carrier, with **Shipped 7 days** and **Backlog**. |
| **Order By Country** | Orders ranked by destination country. |
| **Jobs** | Open jobs grouped by **Priority**, **Status** or **Type**, with **Product Qty**, **Order Qty** and **Job Qty**. |

The header shows the business day and the warehouse time zone. "Today" is the warehouse's day, not your computer's. When you select warehouses in different time zones, the dashboard uses the first warehouse's zone and marks the date with an asterisk. Select one warehouse to see its own day.

## Filter the dashboard

1. Use the **Warehouse** and **Client** filters at the top right.
2. On a phone, select **Filters** first to show them.

When no filter is set, the dashboard follows the working context in the header. See [Navigate the WMS](/docs/wms/navigate-the-app).

## Refresh

The dashboard reloads every 60 seconds. The header shows when it last updated. Select the refresh icon to reload now.

## Customize the cards

1. Select **Customize**.
2. Under **Cards**, clear a checkbox to hide a card, or use the arrows to move it up or down. At least one card stays visible.
3. Under **Open on**, choose a **Default warehouse** and **Default client** if you want the dashboard to open on them. Leave them empty to use the header context.
4. Select **Reset to default** to restore the original layout.

Your layout is saved to your account, so it follows you to other devices.

## The Get set up checklist

On a new install, a **Get set up** panel lists the setup steps in order, with a progress ring and the minutes of work left. Each step checks itself off from live data. When every step is done, the panel shows **Your warehouse is ready**. See [Set up your warehouse step by step](/docs/wms/setup-sequence) for each step.
