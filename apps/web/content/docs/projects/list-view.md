The **List** tab shows a project's tasks as rows, grouped into sections by default. It is the best place to plan the order of work, split a project into phases and edit many tasks quickly.

## Before you start

- To edit tasks or sections you need the Editor or Owner role on the project.

## Read a row

Each row shows a check to mark it done, the key and name, labels, and the **Status**, **Assignee**, **Due** and **Priority** columns. Select any of them to change it in place. Double-click the name to rename the task. A task with subtasks shows a count: select it to show or hide them.

## Add tasks

- Type in **Add a task** at the bottom of a group and press `Enter`.
- Or select the plus next to a group name, which opens quick add with that group filled in.

A task added in a group gets that group's value. For example, adding under the **High** group when grouped by priority makes a high priority task.

## Reorder tasks

Drag a row by its handle (**Drag to move**) to a new place, or into another group. Dropping a task in another group changes that field on the task.

Reordering is off while the list is sorted by something other than **Manual (drag to reorder)**. Switch **Order tasks by** to Manual in **Display** to arrange tasks yourself.

## Work with sections

Sections split a project into phases, such as `Plan`, `Build` and `Launch`.

1. To add one, select **Add section** at the bottom of the list, type a name and press `Enter`.
2. To rename one, open the section menu and select **Rename section**.
3. To add a task to it, open the section menu and select **Add a task here**.
4. To delete one, open the section menu and select **Delete section**.

Deleting a section never deletes its tasks. They stay in the project, under **No section**.

## Display options

Open **Display** in the filter bar.

| Option | Choices |
| --- | --- |
| **Group by** | **Section**, **Status**, **Priority**, **Assignee**, **Label**, **No grouping** |
| **Order tasks by** | **Manual (drag to reorder)**, **Priority**, **Due date**, **Newest first**, **Name (A to Z)** |
| **Done tasks** | Show or hide done tasks |
| **Subtasks opened** | Show every task's subtasks under it |

## Select and edit many tasks

Tick rows, or press `X`, to select them, then use the bar at the bottom to change status, assignee, priority, due date or labels, move or delete. Select every task in a group with the box next to its name. See [views, filters and saved views](/docs/projects/views-and-filters).
