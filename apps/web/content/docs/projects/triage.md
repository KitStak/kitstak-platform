Triage is an intake queue for a project. Requests wait there until someone decides what to do with them: accept one into a task, merge it into a task that already covers it, snooze it, or decline it. The **Triage** tab shows how many requests are waiting.

## Before you start

- Commenters and above can send a request. Editors and owners decide on requests.
- To route an intake form into Triage, turn on **Send responses to Triage first** in the form's settings. See [intake forms](/docs/projects/intake-forms).

## Where requests come from

Each request shows where it came from: **Request** (sent by hand), **Form**, **CRM**, **Warehouse**, **Portal** or **App**.

## Send a request

1. Open the project and select the **Triage** tab.
2. Select **New request**.
3. Fill in **What is needed?**, such as `Add a second dock door to the receiving plan`.
4. Optional: add **Details**, why it matters and anything the team should know.
5. Pick **How urgent is it?**: **Urgent**, **High**, **Medium**, **Low** or **Not sure**.
6. Select **Send request**.

The request waits in the project's Triage until someone accepts it into a task.

## Decide on a request

Use **Show** to pick **Waiting**, **Snoozed** or **Done**. Select a request to see its details, then pick a decision. Each button shows its key.

| Decision | Key | What happens |
| --- | --- | --- |
| **Accept** | `A` | It becomes a task |
| **Merge** | `M` | It is added to a task that already covers it, as a comment |
| **Snooze** | `S` | It leaves the queue and comes back on the day you pick |
| **Decline** | `D` | It leaves the queue. You can still find it under **Done** |

Use `J` and `K` to move between requests.

### Accept a request

1. Select **Accept**.
2. Check the **Task title**.
3. Pick the **Status**. **First column** uses the project's starting status.
4. Optional: set the **Assignee**, **Priority** and **Due date**.
5. Select **Accept as task**.

### Merge a duplicate

1. Select **Merge**.
2. Find the task it duplicates.
3. Pick it. The request text is added to the task as a comment.

### Snooze a request

1. Select **Snooze**.
2. Pick **Tomorrow**, **In 3 days**, **Next Monday**, **In 2 weeks**, or a day.
3. Select **Snooze**.

Snoozed requests come back to **Waiting** on the day you pick.

### Decline a request

1. Select **Decline**.
2. Optional: give a **Reason**, such as `Out of scope for this project`.
3. Select **Decline**.

## Undo a decision

On the **Done** list, each request shows what happened to it: **Accepted**, **Merged** or **Declined**. Select **Put back in the queue** to send it back to **Waiting**.
