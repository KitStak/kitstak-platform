Every project shows the same tasks in six views: **Board**, **List**, **Table**, **Timeline**, **Calendar** and **Workload**. Each view has a filter bar at the top. Filters and layout choices live in the page address, so you can share a link to exactly what you see, and you can save them as a named view.

## Before you start

- Anyone on the project can filter and save a view for themselves. Sharing a view with the project needs the Editor or Owner role.

## Filter a view

The filter bar on Board, List and Table has these parts, from left to right.

| Control | What it does |
| --- | --- |
| **Views** | Pick a saved view, or **All tasks** for every task with your own filters |
| **Search tasks** | Matches the title and the key, such as `OPS-42`. Press `/` or `Ctrl` `F` to jump to it |
| **Mine** | **Only my tasks** shows tasks assigned to you |
| **Filter** | Opens filters for **Assignee**, **Status**, **Priority**, **Labels** and **Due** |
| **Display** | The layout options for this view |
| **Save** | Saves your changes to the view you are on |
| Reset | **Reset filters and layout**, or **Reset to** the saved view |

Active filters show as chips. Select a chip to change it, or its **×** to remove it.

### Filter options

| Filter | Choices |
| --- | --- |
| **Assignee** | **Me**, **Unassigned**, or any person |
| **Status** | Any of the project's statuses |
| **Priority** | **Urgent**, **High**, **Medium**, **Low**, **No priority** |
| **Labels** | Any label, or **No label** |
| **Due** | **Overdue**, **Due today**, **Due this week**, **Due in the next 7 days**, **No due date** |

In programs, a **Work type** filter also picks **Tasks and builds**, **Tasks** or **Builds**.

Projects remembers the last filters you used in each view of each project, and brings them back when you return.

## Save a view

1. Set up the filters, grouping and sorting you want.
2. Open **Views** and select **Save as a new view…**.
3. Give it a **Name**, such as `My urgent tasks`.
4. Under **Who can use it**, pick **Just me** or **Everyone on the project**.
5. Optional: turn on **Open this view first** to open it whenever you open this view.
6. Select **Save view**.

A view you change shows **Unsaved changes**. Select **Save** to update it, or reset to go back.

### Manage saved views

Open **Views** while a saved view is active:

- **Rename** the view.
- **Open this view first**, or **Stop opening this view first**.
- **Delete** the view. For a shared view, everyone on the project loses it. Tasks stay exactly as they are.

Only project editors can share views with everyone. If you are not an editor, a view you save is just for you.

Timeline, Calendar and Workload have their own **Saved views** menu with the same choices: **Only you** or **Shared with the project**.

## Edit many tasks at once

1. In List or Table, tick the box next to each task, or press `X` on a task. `Shift` and click selects a range.
2. Use the bar that appears at the bottom.

| Button | What it does |
| --- | --- |
| **Status** | Moves every selected task to a status |
| **Assign** | Sets the assignee |
| **Priority** | Sets the priority |
| **Due** | Sets the due date |
| **Labels** | Adds a label to every selected task |
| **Move** | **Move to section**, or **Move to another project** |
| **Delete** | Deletes them, with **Undo** |

Press `Esc` or select **Clear selection (Esc)** to stop. You can also press `Ctrl` `K` for the selection commands. See [search and the command palette](/docs/projects/search-and-command-palette).

## Undo

Moves, edits and deletes show an **Undo** button in a message at the bottom of the screen. Press `Ctrl` `Z` to undo the last one.
