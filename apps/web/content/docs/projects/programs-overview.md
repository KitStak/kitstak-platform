A program is ongoing work for one customer: the same kits, built again and again, under one price card. For example, a glove kitting program might build 100 of each glove kit every weekday. Programs live in KitStak Projects next to your projects, with their own sidebar section, directory and pages. Teams that never make a program see no change to their projects.

## Before you start

- To create a program you need the Member, Admin or Owner role in the workspace. Viewers see **You can view programs. Ask an admin to make you a member to create one.**
- Money (revenue, rates and fees) shows only to people allowed to see it. Everyone else sees units and the line **Money is hidden for your role.** See [roles and permissions](/docs/projects/roles-and-permissions).

## The words programs use

| Word | Meaning |
| --- | --- |
| **Program** | Ongoing work for one customer under one price card. It has a key, such as `KITS`, like a project |
| **Variant** | One kit the program makes, such as Small Brown. Variants can come from attributes, like Size and Color |
| **Build** | One batch of one variant for a day. Builds are numbered with the program key, such as `KITS-212` |
| **Run** | All builds of a program for one day made by one schedule. Builds made by hand show as **Unscheduled** |
| **Output** | How many units were built on a build on one day |
| **Unplanned** | A build made while logging output for work nobody planned |
| **Price card** | The program's rates, in dated versions |
| **Schedule** | A repeating rule that makes builds ahead of time |

A program also counts its own unit: kits, orders, units, packs, boxes, or a word you choose.

## Program status

| Status | Meaning |
| --- | --- |
| **Setting up** | Still being set up |
| **Running** | Builds are being made and logged |
| **Paused** | Schedules stop making builds until you resume |
| **Ended** | The program was ended with **End program**, which sets its end date |
| **Archived** | Hidden from the sidebar. Nothing is deleted |

New programs start with these build statuses: **Planned**, **Staged**, **Building**, **Quality check**, **Done** and **Cancelled**. A program can also hold ordinary tasks for prep work, such as ordering more bags.

## The Programs page

1. Go to **Programs** in the sidebar, or press `G` then `R`. The sidebar badge counts running programs.
2. Find a program with **Search programs**, or filter by **Customer**, **Status**, **Health**, **Owner** and **Starred**.
3. Pick a layout: **Cards**, **Table** or **Trends**.

Each card shows the program's status, customer, this month's numbers, a forecast, and today's builds. From the page you can also select **Log output** to log today's output for a program, and **New program**.

With no programs yet, the page says **Run repeat work as programs**. Select **How programs work** for a three-step explainer: add the kits you build, set one price card, and log what you build each day.

## A program's pages

| Tab | What it holds |
| --- | --- |
| **Overview** | This month, the forecast, alerts, today's builds and a setup list |
| **Builds** | Every build, as a board, list, table, timeline, calendar or runs |
| **Variants** | The kits this program makes, with SKUs, default quantities and rates |
| **Price card** | The dated price versions and their lines |
| **Schedule** | Repeating schedules and the next runs |
| **Linked** | Customers, CRM deals, Pulse jobs, WMS records, projects and other programs linked to it |
| **Activity** | Every change |
| **Settings** | General, units and calendar, money, month close, people and the danger zone |

The program header has **Plan builds** (`Shift` `B`) and **Log output** (`O`), plus a menu with **New build**, **Add variants**, **New price version**, **Link Pulse job**, **Copy program**, **Save as template**, **Post an update**, **Statement** (view or download this month's or last month's statement as CSV or PDF), **End program**, **Archive** and **Delete**.

## Floor today

**Floor today** shows every running program's builds for one day in one place, for the people on the floor. It appears in the sidebar while a program is running, and with `G` then `F`. Log output for each program, and select **Close the day for all** when the day is done. See [plan builds and log output](/docs/projects/builds-and-output).

## Programs elsewhere in Projects

- **Home** shows a **Programs today** card.
- **My work** lists your builds for today and earlier, by run, when **Show builds** is on.
- **Automations** has program triggers, such as **all builds of a run are done**. See [automation triggers, conditions and actions](/docs/projects/automation-reference).
- **Forms** can make builds. See [intake forms](/docs/projects/intake-forms).
- **Dashboards** show program units and revenue by month.
