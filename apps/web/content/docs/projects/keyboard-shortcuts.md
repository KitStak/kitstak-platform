Most of KitStak Projects works without the mouse. Press `?` anywhere to see the shortcut sheet, or open **Settings > Keyboard shortcuts** and type a word like “task” or “inbox” to find one. In the tables, `Ctrl` means `⌘` on a Mac. Keys shown one after another, like `G` then `H`, are pressed one at a time, not together.

Letter shortcuts do nothing while you are typing in a text box.

## Anywhere

| Keys | What they do |
| --- | --- |
| `Ctrl` `K` | Search and commands |
| `/` | Filter this view (or search everything) |
| `C` | New task |
| `?` | Show keyboard shortcuts |
| `[` | Collapse or expand the sidebar |
| `G` then `H` | Go to Home |
| `G` then `M` | Go to My work |
| `G` then `I` | Go to Inbox |
| `G` then `S` | Go to Search |
| `G` then `P` | Go to Projects |
| `G` then `G` | Go to Goals |
| `G` then `D` | Go to Dashboards |
| `G` then `A` | Go to Automations |
| `G` then `T` | Go to Templates |
| `G` then `R` | Go to Programs |
| `G` then `F` | Go to Floor today |
| `Ctrl` `Z` | Undo the last change |

`Ctrl` `Z` takes back the last change that showed an **Undo** button. Inside a text box it undoes your typing instead.

## Any task

These work in List, Board, My work and the task panel.

| Keys | What they do |
| --- | --- |
| `J` | Next task |
| `K` | Previous task |
| `Enter` | Open task |
| `Ctrl` `Enter` | Mark done or reopen |
| `S` | Change status |
| `A` | Change assignee |
| `I` | Assign to me |
| `P` | Change priority |
| `D` | Change due date |
| `T` | Make it due today |
| `Shift` `T` | Make it due tomorrow |
| `#` | Change labels |
| `Ctrl` `.` | Copy task link |
| `X` | Select task |
| `Ctrl` `K` | Commands for the selected tasks |
| `Esc` | Close panel or clear selection |

## Board and Focus mode

| Keys | What they do |
| --- | --- |
| `H` | Board: column to the left (or the left arrow) |
| `L` | Board: column to the right (or the right arrow) |
| `F` | My work: start Focus mode |
| `N` | Focus mode: skip to the next task |

## Inbox

| Keys | What they do |
| --- | --- |
| `E` | Archive |
| `U` | Mark read or unread |
| `X` | Select |
| `Shift` `R` | Mark everything read |

## New task box

| Type or press | What it does |
| --- | --- |
| `Enter` | Add the task |
| `Ctrl` `Shift` `Enter` | Add it and open it |
| `tomorrow` | Due date (also `next fri`, `dec 5`) |
| `!high` | Priority (`!urgent` to `!low`) |
| `@name` | Assign someone |
| `#label` | Add a label |
| `+KEY` | Pick the project |

See the [quick add syntax reference](/docs/projects/quick-add-syntax) for every word quick add understands.

## Programs

| Keys | What they do |
| --- | --- |
| `O` | In a program: log output for today |
| `B` | In a program: new build |
| `Shift` `B` | In a program: plan builds |
| `/` | Log output: focus “Scan or type a SKU” |
| `Enter` | Log output: next row |
| `Shift` `Enter` | Log output: previous row |
| `=` | Log output: fill the remaining qty |
| `Ctrl` `Enter` | Log output: save |
| `Esc` | Log output: close (asks about unsaved rows) |
| Arrow keys | Planner: move between cells |
| `Ctrl` `D` | Planner: fill right |
| `Ctrl` `Shift` `D` | Planner: fill down |
| `Delete` | Planner: clear cells |
| `Ctrl` `V` | Planner: paste a block from a spreadsheet |
| `Ctrl` `Enter` | Planner: create builds |

## Triage

On a project's **Triage** tab, the decision buttons show their keys: `A` to accept, `M` to merge, `S` to snooze and `D` to decline the open request.
