A goal is an objective your team is working toward, such as “Ship every order within 24 hours”. You measure it with key results, the projects behind it, or a percent you set by hand, and you post check-ins to say how it is going.

## Before you start

- To create and change goals you need the Member, Admin or Owner role in the workspace.

## Create a goal

1. Go to **Goals** and select **New goal**.
2. Enter the **Goal**, such as `Ship every order within 24 hours`.
3. Optional: write **Why it matters**.
4. Pick the **Owner**.
5. Pick the **Time frame**: a quarter, such as `Q1 2027`, or your own **Starts** and **Due** dates. The due date has to be after the start.
6. Under **Part of a bigger goal**, pick a parent goal, or **No, it’s a top goal**.
7. Pick **How progress is measured**.
8. Optional: pick **Linked projects** and a **Color**.
9. Select **Create goal**.

### How progress is measured

| Choice | How it works |
| --- | --- |
| **From key results** | Average of the key results |
| **From linked projects** | Average of the projects’ completed tasks |
| **Set by hand** | You update the percent at each check-in |

## Add key results

1. Open a goal's menu and select **Add key result**.
2. Write what you will measure, such as `Ship 500 orders a day`.
3. Pick how it is **Measured as**.
4. Fill in the **Start value** and **Target value**, and a **Unit** if it helps.
5. Select **Add key result**.

| Measured as | Use it for |
| --- | --- |
| **Number** | Counting something, like orders shipped |
| **Percent** | A percentage, like on-time rate |
| **Money** | An amount, like revenue |
| **Done or not** | Something that happens once. It is 0% until done, then 100% |
| **Project progress** | Fills in from a project’s tasks |

Progress counts from where a key result started, not from zero. A key result whose target is lower than its start counts as going down, and shows **Lower is better**. Moving the wrong way since the start counts as 0%.

To change a key result's number quickly, select it on the Goals page and type the new value.

## Check in on a goal

1. Select **Check in** on the goal.
2. Pick **How is it going?**: **On track**, **At risk**, **Off track**, **Achieved** or **Missed**.
3. Update the current value of each key result, or **Progress today (%)** for goals set by hand.
4. Optional: write a **Note**.
5. Select **Save check-in**.

Every check-in is kept. Open **Details and history** from the goal's menu to see them. When a linked project's health is at risk or off track, the goal shows a hint to check in.

## Nest goals

Select **Add a smaller goal** from a goal's menu to add a goal under it. The Goals page shows the tree, with each goal's progress.

## Find goals

Use **Find a goal**, **Health** (**Any health** or one health) and **Time frame** (**Any time frame** or one) to narrow the list. The header shows the **Average progress** of top goals.

## Link a project to a goal

- In the goal dialog, pick **Linked projects**.
- A project's **Overview** lists its goals. A project not linked yet says **Not linked to a goal yet. Link it from the Goals page.**

## Change or delete a goal

Open the goal's menu and select **Edit goal** or **Delete goal**. A deleted goal shows an **Undo** button right after.
