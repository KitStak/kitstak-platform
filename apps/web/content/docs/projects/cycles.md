A cycle is a short round of work inside a project, usually one or two weeks, with a goal the team can check the work against. You pull tasks from the backlog into the cycle, follow its burndown, and when it ends, unfinished work rolls into the next one.

## Before you start

- You need the Editor or Owner role on the project to plan, edit or close cycles.

## Plan a cycle

1. Open the project and select the **Cycles** tab.
2. Select **Plan a cycle**.
3. Optional: give it a **Name**, such as `Peak prep week 1`. Leave it empty to call it by its number, such as `Cycle 3`.
4. Pick the **Start date** and **End date**, or select **1 week**, **2 weeks** or **3 weeks** to set the length.
5. Optional: write a **Goal**, one sentence the team can check the work against.
6. Leave **Roll over unfinished work** on to move open tasks to the next cycle when this one ends.
7. Select **Plan cycle**.

### Cycle rules

- The end date has to be on or after the start date.
- A cycle can be up to 13 weeks long.

## Add tasks to a cycle

1. Open the cycle on the **Cycles** tab.
2. Under **Backlog**, find tasks with **Find a backlog task**. The backlog holds the project's open tasks that are not in a cycle yet.
3. Tick the tasks you want.
4. Select **Add** and the number of tasks, such as **Add 4 to cycle**.

To take a task out, select the remove button next to it in **In this cycle**.

A task is in one cycle at a time. Subtasks follow their parent task, so add the parent. Tasks from one project only. A closed cycle cannot take new tasks.

## Follow a cycle

Each cycle is **Current**, **Upcoming** or done. The current cycle shows:

| Number | What it means |
| --- | --- |
| **Done** | The share of tasks finished, and how many of how many |
| **Left to do** | Open tasks, plus points left when tasks have points |
| **Scope change** | Tasks added or taken out after the cycle started |
| **Rolled over** | Tasks that moved on, or will move on if still open at the end |

The **Burndown** chart shows **Work left** against an **On-time pace** line. Staying under the dashed line means the cycle is on pace. The **Scope changes** chart shows tasks added (up) or taken out (down) after the cycle started.

On the **Board** and **List** tabs, a slim strip shows the current cycle, its dates, days left, progress and goal, with **Open cycle**.

## Close a cycle

A cycle closes by itself once its end date has passed. With **Roll over unfinished work** on, open tasks move to the next cycle, and Projects plans the next one for you with the same length if there isn't one.

To close it early:

1. Open the cycle and select **Close cycle**.
2. Under **Unfinished tasks**, pick **Move to next cycle** or **Back to backlog**.
3. Select **Close cycle**.

To change a cycle's name, dates, goal or rollover, select **Edit**. To delete it, select the bin button next to **Close cycle**.

## See cycles in the table

The **Table** view has a **Cycle** column that shows each task's cycle.
