Each task keeps its own conversation, files, followers and time log. Everything sits in the task panel, below the description.

## Before you start

- Commenters can comment and upload files. Editors and owners can also log time. Viewers can only look. See [roles and permissions](/docs/projects/roles-and-permissions).

## Write a comment

1. Open the task.
2. Select **Write a comment… Type @ to mention someone**.
3. Type your comment. To mention a teammate, type `@` and their name, then pick them from the list.
4. Optional: use the bar for **Bold**, **Italic**, **Code**, **Bulleted list**, **Checklist** and **Add link**, or select **Attach files**.
5. Select **Comment**, or press `Ctrl` `Enter`.

A person you mention gets a notification in their inbox.

### React, edit and delete

- Select **Add a reaction** and pick one of eight emoji. Select a reaction someone else left to **React too**, or your own to **Remove your reaction**.
- Open the comment's menu for **Copy link**, **Edit** and **Delete**. You can edit and delete your own comments. **Comment deleted** shows an **Undo** button.

### Comments and history

The bottom of the panel has three tabs: **Everything**, **Comments** and **History**. **History** lists every change to the task, such as status moves and new assignees. Changes made by a rule show **Automation** as the person. Your choice of tab is remembered in this browser.

## Attach files

1. Open the task.
2. Drag files onto the **Files** section, or select **browse**.

Files can be up to 25 MB each. Images open in a viewer with **Previous image** and **Next image**. Every file has **Download** and **Delete**. Files attached to tasks also show on the project's **Files** tab.

## Follow a task

Followers get updates when a task changes or gets a comment. The person who created a task and its assignee follow it from the start.

- To follow, open **More actions** and select **Follow this task**. To stop, select **Stop following**.
- The **Followers** list in the panel shows who follows it.

Choose which updates reach you in [your notification settings](/docs/projects/inbox).

## Track time

The **Time** section shows a timer, the time logged so far, and how it compares with the estimate.

### Use the timer

1. Open the task and select **Start timer**.
2. Keep working. The timer keeps running when you close the task or reload the page, and a **Timer running** pill shows in the top bar.
3. Select **Stop timer** to stop it and save the time.

You can run one timer at a time. Starting a timer on another task stops and saves the one that was running. A stopped timer logs at least one minute.

### Log time by hand

1. In the **Time** section, select **Log time**.
2. Type how long, such as `45m`, `1h 30m` or `2:15`.
3. Pick the **Day worked**. It starts as today.
4. Optional: write **What did you do?**
5. Optional: tick **Billable** if the time is billable to the client.
6. Select **Log time**.

One entry can be up to 24 hours. Every entry shows who logged it and whether it came from the timer or was **Added by hand**. Select **Delete this entry** to remove one.
