The command palette is the fastest way to move around KitStak Projects. Open it, type a few letters, and jump to a task, project, program, person or goal, or run a command. For a full list of results with filters, use the **Search** page.

## Open the command palette

- Press `Ctrl` `K` (`⌘` `K` on a Mac) anywhere.
- Or select **Search** in the top bar.

The box says **Search tasks, projects, programs and people, or type a command…**. Use the arrow keys to move, `Enter` to open and `Esc` to close. Type a task key like `OPS-12` to jump straight to that task.

## What the palette offers before you type

| Group | What it holds |
| --- | --- |
| **Create** | **New task** (`C`), **New project**, and program commands such as **New program** and **New build** |
| **In** the current project | Every tab of the project you are in, plus **New task in this project** |
| **Jump to a project** | Your projects, with their keys |
| **Go to** | **Home**, **My work**, **Inbox**, **Search**, **Projects**, **Programs**, **Floor today**, **Goals**, **Dashboards**, **Automations**, **Templates**, **Forms** and **Settings** |
| **Switch organization** | Shown when you belong to more than one organization |
| **KitStak apps** | **Open Portal**, plus **Open CRM** and **Open WMS** when your organization has them |
| **Preferences** | **Dark mode**, **Light mode**, **Keyboard shortcuts** and **Sign out** |

The **Settings** tab of a project shows in the palette only for its owners and editors.

## What the palette offers as you type

- **Tasks** that match your words, with their key and project. Builds carry a **Build** tag.
- **New task “your words”** opens quick add with your text. Dates, `!priority`, `@people` and `#labels` are filled in for you.
- **Search everything for “your words”** opens the Search page.
- **People** who match. Selecting a person shows their open tasks.
- **Goals** and **Programs** that match.

## Run commands on selected tasks

1. In a List, Board or Table view, select tasks with `X` or their checkboxes.
2. Press `Ctrl` `K`.
3. Pick a command from the selection group at the top.

| Command | What it does |
| --- | --- |
| **Mark done** | Moves every selected task to the project's done status |
| **Set status:** a status | Moves them to that status |
| **Assign to me** | Makes you the assignee |
| **Unassign** | Clears the assignee |
| **Set priority:** a priority | Sets **Urgent**, **High**, **Medium**, **Low** or **No priority** |
| **Make them due today** | Sets today as the due date |
| **Make them due tomorrow** | Sets tomorrow as the due date |
| **Clear the due date** | Removes the due date |

## Use the Search page

1. Go to **Search** in the palette, or press `G` then `S`.
2. Type in the box that says **Search by words, a task key like OPS-12, or a person**.
3. Narrow the results with the filters.

| Filter | Options |
| --- | --- |
| **Result type** | All, **Tasks**, **Comments**, **Projects**, **Programs**, **People**, **Goals** |
| **Project** | **All projects** or one project |
| **Assignee** | **Anyone**, **Me**, **No one** or a person |
| **Task state** | **Any state**, **Open** or **Done** |

If nothing matches, Projects suggests checking the spelling, using fewer words, or searching for a task key. With no words but a person or project picked, the page lists those tasks.
