A template is a reusable project plan. It brings its own statuses, sections, labels, custom fields, milestones, automations and starter tasks. KitStak Projects has seven built-in templates, and your team can save any project as its own.

## Before you start

- To use or save templates you need the Member, Admin or Owner role in the workspace.

## Browse templates

1. Go to **Templates**.
2. Use **Search templates** or **Category** to narrow the list.
3. Select **Preview** on a template to see what it sets up.

The preview lists the **Steps every task moves through**, the tasks and subtasks, **Milestones**, **Labels and fields** and **Automations included**. Templates that work best with a customer say **Asks which client it’s for**. Built-in templates carry a **Built in** tag; your team's carry **Your team**.

### What each one sets up

| Template | Statuses | Sections | Labels and fields |
| --- | --- | --- | --- |
| **Product launch** | To do, In progress, In review, Done | Plan, Build the launch kit, Launch week, After launch | Copy, Design, Sales |
| **Client onboarding** | Not started, Working on it, Waiting on client, Done | Kickoff, Set up, Go live | Client action |
| **Warehouse go-live** | To do, In progress, In review, Done | Setup, Receiving and stock, Orders and shipping | WMS setup, Warehouse floor |
| **Sales deal handoff** | To do, In progress, Needs sales input, Done | Handoff, Kickoff, First delivery | Sales, Delivery, Billing, and a Deal value money field |
| **Two-week sprint** | Backlog, Ready, In progress, Code review, Done | None | Bug, Feature, Chore, and an Area choice field |
| **Event plan** | To do, In progress, In review, Done | Planning, Promotion, Event day, Follow-up | A Cost money field |
| **Marketing campaign** | Ideas, Writing, Needs approval, Scheduled, Published | None | Email, Social, Ads, Blog |

Client onboarding, Warehouse go-live and Sales deal handoff ask which customer the project is for. The Two-week sprint limits **In progress** to 5 tasks and **Code review** to 3.

## Start a project from a template

1. Select **Use template** on a card, or **Use this template** in the preview.
2. The **New project** wizard opens with the template picked. See [create a project](/docs/projects/create-a-project).

The project's due date is set from the template's length, counted from your start date. Starter tasks get dates counted from the start date too. A date that falls on a weekend moves to the next Monday. Turn off **Add the starter work** in the wizard to get only the columns, labels and milestones.

## Save a project as a template

1. Go to **Templates** and select **Save a project as template**. You can also do this from a project's **Settings > Archive & delete > Save as a template**.
2. Pick the **Project to copy**.
3. Enter the **Template name** and **What is it for?**
4. Pick a **Category**: General, Operations, Customer success, Sales, Marketing, Engineering or Events.
5. Leave **Include the tasks and subtasks** on to copy the work too.
6. Select **Save template**.

New projects made from it start with the same steps, sections, labels, fields, milestones and automations. Due dates are saved as “day 3”, “day 10” and so on, so they fit any start date. People and comments are not copied.

## Change or delete your team's templates

Open a template's menu and select **Rename or describe** or **Delete**. Built-in templates can't be changed. A deleted template shows an **Undo** button right after.

## Program templates

The **Program templates** section lists programs your team saved as templates: their kits, price card lines and schedules. Dates and output are never copied. See [create a program](/docs/projects/create-a-program).
