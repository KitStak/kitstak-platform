The **Table** tab shows a project's tasks as a spreadsheet. Every field is a column, custom fields included. Edit any cell in place, sort and group by columns, and download what you see as a CSV file.

## Before you start

- To edit cells you need the Editor or Owner role on the project.

## Columns

| Column | What it shows |
| --- | --- |
| **ID** | The task key, such as `OPS-42` |
| **Task** | The task name. It always shows and stays in place as you scroll |
| **Status** | The task's status |
| **Assignee** | Who does the work |
| **Priority** | **Urgent** to **No priority** |
| **Start date** and **Due date** | The task's dates |
| **Labels** | Its labels |
| **Section** | Its section, or **No section** |
| **Points** | Story points |
| **Time estimate** | The time it should take |
| **Subtasks** | How many subtasks are done |
| **Cycle** | The cycle it is in |
| **Linked to** | Linked CRM and WMS records |
| **Customer** | The linked customer |
| **Created** and **Updated** | When it was made and last changed |
| Custom fields | One column per custom field, under **Custom** |

## Choose, order and resize columns

1. Select **Columns** in the filter bar.
2. Turn columns on or off. Drag them to change their order.
3. To resize a column, drag the edge of its header.

Select **Add a column** at the end of the header row to turn on another column. When every column is on, it says **Every column is showing**.

## Edit cells

- Select a cell and type, or press `Enter` to edit it. Press `Esc` to cancel.
- Move with the arrow keys. `Tab` goes to the next cell.
- Select **Open** next to a task name to open the task.

## Sort and group

- Select a column header to sort by it. Hold `Shift` and select another header to add a second sort.
- Open a header's menu for **Sort A → Z / low → high**, **Sort Z → A / high → low**, **Remove this sort**, **Group by** that column and **Hide column**.
- Or open **Display** and pick **Group by**: **No grouping**, **Status**, **Assignee**, **Priority**, **Section**, **Label** or a single choice **Custom field**.

## Totals

The last row adds up number columns for the tasks you can see, such as points, time estimates and number or money custom fields. Point at a total to see **Total of the shown tasks**.

## Display options

| Option | What it does |
| --- | --- |
| **Group by** | Groups the rows |
| **Done tasks** | Shows or hides done tasks |
| **Subtasks as rows** | Shows subtasks as their own rows |
| **Download as spreadsheet (CSV)** | Downloads the shown rows and columns |

## Download a CSV

1. Set the filters and columns you want.
2. Open **Display** and select **Download as spreadsheet (CSV)**.

The file holds exactly the rows and columns you see. Open it in Excel, Numbers or Google Sheets. Accented names open correctly in Excel.

## Add tasks and edit many at once

Type in **Add a task** at the bottom of the table, or at the bottom of a group. Tick rows, or press `X`, to select them for the bulk bar. Select every task with the box in the header. See [views, filters and saved views](/docs/projects/views-and-filters).
