After you start your free trial, KitStak emails you a 6 digit code. Entering it proves the address is yours. You can skip it for now and keep working, but some steps wait for it.

## What needs a verified email

| Task | What you see until you verify |
| --- | --- |
| Invite people | **Verify your email first. It takes one minute. Then you can invite people.** with **Enter code** |
| Pay for a plan or change a paid plan | **Verify your email first. It takes one minute.** under the pay button |
| Everything else | Works as usual. The Portal shows **Enter the 6 digit code we emailed you.** with **Enter code** at the top. |

## Enter the code

1. Open the email from KitStak with the subject that starts **Your KitStak code**.
2. On the **Check your email** screen, type or paste the code in **6 digit code**. Spaces and dashes in a pasted code are dropped.
3. The form checks the code as soon as 6 digits are in. You can also select **Verify email**.
4. The button reads **Checking your code…** and then **Email verified**. You go on to where you were headed.

The screen says how many minutes the code works for.

## Get a new code

1. Select **Send a new code**.
2. If you just asked for one, the link reads **Send a new code in** and a number of seconds. Wait for it to count down.

## Fix a wrong address

1. Under the form, next to **Typed the wrong address?**, select **Change email**.
2. Type the address in **Your right email**.
3. Select **Save and send a new code**. Your account, your organization and your free trial stay as they are.
4. To leave it as it was, select **Go back**.

## Skip for now

Select **I will do this later**. You go on to the welcome screen or the page you wanted. You can verify any time from the notice at the top of the Portal, or from **Account menu > My account**, where the **Email** card has **Verify my email**.

## Wrong account

If this is not your account, select **Sign out and start again** next to **Not your account?**.

## Messages you may see

| Message | What to do |
| --- | --- |
| Enter the 6 digit code from your email. | Type all 6 digits. |
| That code is not right. Check it and try again. | Check the code in the newest email from KitStak and type it again. |
| We could not send the code. Try again. | Wait a moment and select **Send a new code** again. |
| We could not change your email. Try again. | Check the new address and try again. |
