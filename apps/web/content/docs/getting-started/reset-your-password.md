All password changes in KitStak go through the Portal and use a 6 digit code sent to your email. This proves the request came from you. After a new password is saved, every other device is signed out.

## Reset a forgotten password

1. On the sign in page, select **Forgot password?** next to **Password**.
2. On **Reset your password**, type your **Work email**.
3. Select **Send code**. The button reads **Sending your code…**.
4. The next screen, **Choose a new password**, says **If that email has an account, we sent a 6 digit code.** It always says this, whether or not the address has an account.
5. Type the code from the email in **6 digit code**.
6. Type a new password in **New password**. The same meter and checklist as sign up show under it. See [Password rules](/docs/getting-started/password-rules).
7. Select **Save new password**. The button reads **Saving your new password…**.
8. You go to the sign in page with **Your password is changed. Sign in with your new password.**

The screen says how many minutes the code works. If it runs out, select **Send a new code** on the same screen. You then see **If that email has an account, we sent a new 6 digit code.**

> **Note:** A reset also clears a lockout from wrong passwords, so you can sign in with the new password at once.

## Change a password you know

1. Open the **Account menu** in the top bar and select **My account**.
2. In the **Password** card, select **Change my password**.
3. Follow the reset steps above. The card says **To change it, we email you a 6 digit code first. Every other device is signed out when you save the new one.**

## Set a password for the first time

If you signed up with **Email me a code instead**, or with Google or Microsoft, you may have no password. You can add one in [My account](/docs/getting-started/my-account). A password is one more way in. The code by email keeps working.

## Replace a temporary password

When an admin sets up your account with a temporary password, KitStak asks you to replace it the first time you sign in. The Portal and the CRM send you to **Choose a new password** until you do.

1. Type the password you were given in **Temporary password**.
2. Type your own password in **New password**.
3. Type it again in **Confirm new password**.
4. Select **Save and continue**. You go back to the app you came from.

| Message | What to do |
| --- | --- |
| Enter the password you were given. | Fill in **Temporary password**. |
| That is not the password you were given. Check it and try again. | Check the temporary password with your admin. |
| Choose a password that is different from the one you were given. | Pick a new password. |
| The two passwords do not match. | Type the same password in both fields. |

If this is not your account, select **Sign out** next to **Not you?**.

## Messages you may see

| Message | What to do |
| --- | --- |
| Enter a valid email. | Check the address. |
| Enter the 6 digit code from your email. | Type all 6 digits. |
| Something went wrong. Please try again. | Wait a moment and try again. |
